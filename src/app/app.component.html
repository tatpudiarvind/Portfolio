Code review time,

I built a GitHub Copilot review agent that checks every pull request against our written guidelines, and MCP-based tools that turn a failing system’s logs into a draft root-cause analysis. My whole team uses both every day.

Time spent on code review
70% less
Defect analysis
3× faster
How it works, and how we check it ＋

The review agent pulls each pull request through Azure DevOps MCP tools, reads every changed file in full and checks it against our written guidelines, plus a short playbook per repository. The playbooks hold what the agent can’t learn from the code, such as conventions that differ between repositories on purpose. Each finding names the file, line, broken rule, severity and a suggested fix, and a second agent applies the fixes the reviewer accepts.

It may only flag what a written guideline or a clear security risk backs, it never posts without the reviewer’s confirmation, and every comment is tagged “AI reviewed”. Fixes must preserve behaviour and compile. The defect tools read event logs, product logs, crash dumps and call traces, find the responsible module and whether it’s ours, and draft an RCA with timeline, diagnosis, fix and performance impact, which the engineer confirms before changing code.

These are internal tools, so product and system details are kept general.

What changed ＋

The pipelines cover Angular and .NET builds, unit and Playwright tests, SonarQube quality gates, versioned Docker images, Azure provisioning, database migrations, Kubernetes deployment and publishing the API to Azure API Management.

I traced seven classes of build and deploy failure, from private npm feeds to EF Core migrations and Azure permissions, and documented each fix in a handover guide. Running the container as non-root met the cluster’s security policy, and fixing a critical cross-window messaging issue lifted the security rating.

How ＋

The agent collects device and subsystem data, queues registry updates and syncs them to the cloud over authenticated REST APIs. On the data side, composite indexes and normalised keys sped up clearance queries, and a single binary-COPY upsert replaced per-row writes.
